The project story

Why we built RomeroOps-AI

Incidents rarely arrive with a complete explanation. Engineering teams need a way to notice a problem, investigate it, ask follow-up questions, and find relevant history—without making every step manual.

01
Detect and investigate

Monitoring events can start a Python Lambda investigator that uses Bedrock Nova Lite, saves findings, and notifies responders by SNS email.

02
Ask the operations assistant

An operator sends /compliment or /investigate in Slack. The EC2 Node.js agent uses Bedrock for AI replies or calls the RAG API for historical incident matches. Slack credentials are retrieved from AWS Secrets Manager.

03
Learn from historical incidents

The browser dashboard and Slack /investigate command use the same API Gateway and RAG Lambda to retrieve simulated incident evidence from a Bedrock Knowledge Base backed by S3.

Architectural idea: RomeroOps-AI has three entry points: automated incident monitoring, Slack commands, and the browser dashboard. Today, Slack /investigate is also connected to the RAG API, while /compliment uses Bedrock model inference. These are separate workflows within one platform.

Evidence: working Slack commands, RAG API integration, and automated incident investigation
What was actually tested: Slack /compliment → EC2 → Bedrock model → Slack; Slack /investigate → EC2 → API Gateway → RAG Lambda → Knowledge Base → five historical matches in Slack; EC2 → Secrets Manager for Slack credentials; CloudWatch → EventBridge → Lambda → Bedrock Nova Lite → S3 / SNS → email; and dashboard → API Gateway → RAG Lambda → Knowledge Base returning five matches. Not verified: automated incident alerts delivered directly into the Slack agent or a direct handoff from the automated incident investigator to the RAG Lambda. Those are potential integrations, not built links.

This page demonstrates the documented build and past tests; it is not live incident telemetry, a current AWS health check, or a statement that every IAM policy was audited. All application data shown is fictional.
